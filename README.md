# Women’s Fitness

Премиальное фитнес-приложение для девушек: персональная программа, 3D-демонстрация упражнений,
дневник тренировок, питание и прогресс. Открывается в браузере и устанавливается на главный экран
телефона как обычное приложение (PWA), работает без интернета.

## Запуск

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm run build      # продакшен-сборка в dist/
npm run preview    # просмотр сборки: http://localhost:4173
```

Проверки:

```bash
npm test                                   # модульные тесты логики (план, питание, статистика, словари)
npm run preview & npm run e2e              # сквозной тест в мобильном окне (URL=http://localhost:4173/)
```

## Как открыть на телефоне

Приложению нужен любой статический хостинг с HTTPS — сервер и база данных не требуются.

**GitHub Pages (workflow уже в репозитории):** Settings → Pages → Source: «GitHub Actions», затем
влить ветку в основную — сайт соберётся и опубликуется автоматически.
Подойдут также Netlify / Vercel / Cloudflare Pages: команда `npm run build`, папка `dist`.

Установка на главный экран (то же самое описано в приложении: Профиль → «Установить приложение»):

- **iPhone (Safari):** «Поделиться» → «На экран „Домой“» → «Добавить».
- **Android (Chrome):** меню ⋮ → «Установить приложение».

## Архитектура

```
src/
  domain/     чистая бизнес-логика: типы, генератор плана, питание, статистика, даты, единицы (+ тесты)
  data/       каталог упражнений, продукты, цитаты (RU/PL)
  store/      состояние приложения (zustand) с сохранением на устройстве
  storage/    слой хранения: localStorage, IndexedDB для фото, контракт SyncAdapter для сервера
  three/      3D: риг и IK (rig.ts), сцена (stage.ts), позы (pose.ts), анимации упражнений (anims.ts)
  ui/         компоненты дизайн-системы: кнопки, листы, колесо, графики, 3D-вьюер
  screens/    экраны
  i18n/       словари ru.ts / pl.ts (ключи проверяются типами и тестом)
  styles/     дизайн-токены, светлая и тёмная темы
```

- **Данные** хранятся только на устройстве. `storage/adapter.ts` описывает контракт `SyncAdapter`
  (пользователь, pull, push) — точка подключения авторизации и серверной синхронизации.
- **Three.js** загружается отдельным чанком только на экранах с 3D; списки используют готовые миниатюры.
- **Миниатюры и карты мышц** — рендер той же 3D-сцены (`npm run dev` + `npm run render:media`),
  поэтому картинка всегда соответствует упражнению.

## 3D-модель и анимации

**Модель** — девушка в спортивной форме из библиотеки [Microsoft Rocketbox](https://github.com/microsoft/Microsoft-Rocketbox)
(`Sports_Female_01`, лицензия MIT, текст — `public/models/LICENSE-Microsoft-Rocketbox.txt`). Исходный FBX
сконвертирован в GLB без текстур: в приложении она выглядит как серая «скульптура».

**Мышцы** рисуются прямо на модели во фрагментном шейдере (`src/three/rig.ts`): каждая головка мышцы — веретено
вдоль кости в исходной позе. Это даёт гладкие контуры, волокна и рельеф при любой детализации сетки, а подсветка
остаётся «приклеенной» к телу во время движения. Три уровня: основные мышцы, дополнительные, стабилизаторы —
они заданы для каждого упражнения в `src/data/exercises.ts`.

**Анимации** процедурные: ключевые позы + инверсная кинематика (стопы на платформе, кисти на грифе).
Это демонстрация рисунка движения, а не запись motion capture. Позы описаны в осях персонажа, а не в локальных
осях костей, поэтому не привязаны к файлу: поддерживаются скелеты Mixamo и 3ds Max Biped, модель в A-позе
автоматически приводится к T-позе. Чтобы подставить свою модель, замените `public/models/athlete.glb`
и перегенерируйте медиа (`npm run dev` + `npm run render:media`).

## Важно

Приложение не является медицинским изделием. Расчёт калорий ориентировочный; дефицит ограничен
(не ниже базового обмена и 1200 ккал, без дефицита до 18 лет и при низком ИМТ), целевой вес не может быть
ниже здоровой границы для роста.
